# Aya's Playground

Gambar karakter dan rumahnya sendiri, lalu lihat semuanya hidup. Satu file HTML, jalan di browser HP atau tablet, tanpa server.

- Karakter: gambar per bagian (ikuti garis atau bebas) atau **dari foto** gambar di kertas
- Rumah: susun ruangan bertingkat, gambar isinya (kursi, kompor, kasur, dll.) atau pakai foto sebagai latar
- Karakter bergerak, berinteraksi dengan benda, plus aksi hai, lompat, lari, dansa, putar
- BGM dan SFX dibuat langsung di browser (Web Audio), tanpa file audio
- Data tersimpan di perangkat (IndexedDB), tidak ada yang dikirim ke mana pun

Buka `index.html`, atau lewat GitHub Pages.
